# Point & Read (포리)

포리는 난독증이 있거나 글을 읽는 데 어려움을 겪는 사람이 인쇄물에서 필요한 내용을 듣도록 돕는 안드로이드 읽기 보조 앱입니다.

## 주요 기능

- 카메라 영상에서 검지 끝을 찾으면 손끝에 동그라미가 나타납니다. 카메라 탭에서 ‘손끝 표시’를 켜고 끌 수 있습니다.
- 손끝 근처의 글줄을 강조하고, 잠시 안정적으로 가리키면 한국어 음성으로 한 번 읽습니다.
- 화면을 눌러 글줄을 선택할 수 있고, 음성을 일시정지하거나 다시 재생할 수 있습니다.
- 첫 실행 시 화면과 음성으로 사용법을 안내합니다.
- ‘읽은 글’ 탭에서 끝까지 들은 글을 다시 보거나 들을 수 있습니다. 개별 삭제와 확인 후 전체 삭제를 지원합니다.
- 카메라 영상과 글 인식은 기기 안에서 처리합니다. 기록에는 읽기를 마친 문장과 시각만 남습니다. 기록은 앱의 백업 제외 폴더에 저장합니다.

## 실행 환경

- Android 9 (API 28) 이상
- Android SDK Platform 37.0, Build Tools 37.0.0
- Android Studio 내장 JDK

## 빌드

저장소를 내려받은 뒤 Android Studio에서 프로젝트를 열고 Gradle 동기화를 완료합니다. USB 디버깅을 켠 안드로이드 휴대폰을 연결하고 Run을 누르면 설치할 수 있습니다.

명령줄에서는 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
./gradlew :app:assembleDebug
```

Windows에서는 `gradlew.bat :app:assembleDebug`를 실행합니다. APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 첫 빌드에는 Gradle 의존성을 내려받기 위한 인터넷 연결이 필요합니다.

## 인식 및 음성

CameraX의 `ImageAnalysis`에서 받은 프레임을 미리보기와 같은 영역으로 자르고 회전합니다. MediaPipe Hand Landmarker가 검지 끝을 추적하고, 별도 작업에서 ML Kit의 내장 한국어 모델이 같은 프레임의 글줄을 찾습니다. 손끝 상태는 OCR을 기다리지 않고 표시됩니다.

1. 카메라에 한글 인쇄물과 손바닥, 검지가 함께 보이게 합니다. ‘손끝 표시’를 켜고 동그라미가 검지를 따라가는지 확인합니다.
2. 읽을 줄 바로 아래를 가리키고 잠시 멈춥니다. 강조된 줄이 한 번 들리면 다른 줄을 가리켜 봅니다. 손을 찾기 어려우면 화면의 글줄을 누릅니다.
3. 소리가 들리지 않으면 화면의 음성 상태와 기기 미디어 음량을 확인합니다. ‘음성 설정 열기’ 안내가 나오면 기기의 TTS 설정에서 오프라인 한국어 음성을 설치하거나 해당 음성을 제공하는 엔진을 선택하고 앱으로 돌아옵니다.
4. 한 줄을 끝까지 들은 뒤 ‘읽은 글’을 엽니다. 앱을 다시 열어도 문장과 시각이 남고, 기록에서 다시 들어도 항목이 늘지 않습니다. 중지하거나 다른 줄로 전환해 재생이 끊긴 문장은 저장하지 않습니다.

휴대폰 없이 시험할 때는 Android 에뮬레이터의 후면 카메라에 웹캠을 연결하거나, 검지와 인쇄물이 함께 나오는 영상을 입력할 수 있습니다. 예를 들어 SDK의 `emulator -avd PoriPreview -camera-back "videofile:/path/to/pointing.mp4"`에서 가상 기기 이름과 영상 경로를 바꿔 실행합니다. [Android 에뮬레이터 카메라 입력 옵션](https://developer.android.com/studio/run/emulator-commandline#startup-options)

작거나 흐릿한 글, 촘촘한 줄 간격, 손가락에 가려진 글자는 잘못 인식할 수 있습니다. 검지 끝만 화면에 크게 잡히면 손을 찾기 어렵습니다. 실물 휴대폰의 자동 초점, 손떨림, 스피커 출력은 기기에서 확인해야 합니다.
