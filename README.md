# Point & Read (포리)

포리는 난독증이 있거나 글을 읽는 데 어려움을 겪는 사람이 인쇄물에서 필요한 내용을 듣도록 돕는 안드로이드 읽기 보조 앱입니다.

## 주요 기능

- 카메라 영상에서 한국어 글과 검지 끝을 인식합니다.
- 손끝 근처의 글줄을 강조하고, 잠시 안정적으로 가리키면 한국어 음성으로 읽습니다.
- 화면을 눌러 글줄을 선택할 수 있고, 음성을 일시정지하거나 다시 재생할 수 있습니다.
- 첫 실행 시 화면과 음성으로 사용법을 안내합니다.
- 카메라 영상과 인식한 글은 기기 안에서 처리합니다.

## 실행 환경

- Android 9 (API 28) 이상
- Android SDK Platform 37.0, Build Tools 37.0.0
- Android Studio 내장 JDK

## 빌드

저장소를 내려받은 뒤 Android Studio에서 프로젝트를 열고 Gradle 동기화를 완료합니다. USB 디버깅을 켠 안드로이드 휴대폰을 연결하고 Run을 누르면 설치할 수 있습니다.

명령줄에서는 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
./gradlew :app:assembleDebug
```

Windows에서는 `gradlew.bat :app:assembleDebug`를 실행합니다. APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. 첫 빌드에는 Gradle 의존성을 내려받기 위한 인터넷 연결이 필요합니다.

## 인식 및 음성

한글 OCR에는 Google ML Kit Text Recognition Korean을, 손끝 인식에는 MediaPipe Hand Landmarker를 사용합니다. 손끝이 글자를 가릴 수 있으므로 읽을 줄 바로 아래를 가리키는 사용법을 권장합니다. 글자 크기, 조명, 카메라 초점, 줄 간격에 따라 인식 결과가 달라질 수 있습니다. 손 인식이 어려운 경우 화면에서 글줄을 눌러 선택할 수 있습니다.

한국어 오프라인 TTS 음성은 기기에 설치되어 있어야 합니다. 앱에서 음성 설정 안내가 보이면 안드로이드 음성 설정에서 한국어 데이터를 설치하세요.

실물 휴대폰에서 손끝 인식 정확도와 낭독 성능은 아직 검증하지 않았습니다.
